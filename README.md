# Hotel Booking Cancellation Analysis

## About the Project
This project analyzes hotel booking data to understand
booking cancellation patterns and reservation behavior.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
Hotel Booking Demand Dataset from Kaggle.

## Analysis Areas
- Overall booking cancellation
- City Hotel vs Resort Hotel
- Lead time analysis
- Monthly cancellation trends
- Customer type analysis
- Deposit type analysis
